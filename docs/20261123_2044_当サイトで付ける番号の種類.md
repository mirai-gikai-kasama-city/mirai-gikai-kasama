# 当サイトで付ける番号の種類

笠間市議会の会議録には、市の番号（「議案第1号」「選挙第2号」など）が付いていない議事がある。
議長の辞職の許可、委員の選任、会期の決定などである。
これらも載せるため、当サイトが便宜的に番号を付ける（運営者と決めた。2026-11-23）。

## 番号の形

- 「種類-番号」の形にする（例：選任-1）。市の「第○号」の形と見分けられるようにするため。
- 番号は、会期ごと・種類ごとに、会議録の議事の順に1から振る。あとで別の会期を足しても番号がずれない。
- 議案のページには、次の文を添える。

  > この番号は当サイトで便宜的に付けたものです（市側が付けた番号ではありません）

## 種類の一覧

| 種類 | 入るもの | 結果の語 | 同じ日の中の位置 |
|---|---|---|---|
| 手続 | 会期の決定、会議録署名議員の指名 | 決定／指名 | 市の番号がある議案より前 |
| 諸般 | 諸般の報告（意見書の送付、専決処分の報告、財政の健全さの数値、監査の結果など） | 報告 | 前 |
| 施政 | 市長の施政方針 | 報告 | 前 |
| 付託 | 請願・陳情を委員会に任せること | 付託 | 前 |
| 継続 | 委員会の閉会中の継続審査・継続調査 | 決定 | 後ろ |
| 辞職 | 議長・副議長の辞職の許可 | 許可 | 後ろ |
| 選挙 | 番号のない選挙（議長・副議長、一部事務組合の議会議員など） | 当選 | 後ろ |
| 議席 | 仮議席・議席の指定、議席の変更 | 決定 | 後ろ |
| 選任 | 委員会の委員の選任 | 選任 | 後ろ |
| 推薦 | 農業委員の推薦 | 決定 | 後ろ |
| 設置 | 特別委員会の設置 | 決定 | 後ろ |
| 派遣 | 議員の派遣 | 決定 | 後ろ |
| 中間 | 特別委員会の中間報告 | 報告 | 後ろ |

- 「選挙」は、市の番号がある「選挙第1号」と同じ種類名にしている。番号のあるなしに関係なく、選挙をまとめて見られるようにするため。
- 「付託」「継続」「施政」「中間」は、最初の案に無く、会議録を調べて足したもの（運営者の了承済み）。
- 一般質問は議案の一覧には入れず、「一般質問を検索」のページに入れる（運営者の判断。2026-11-23）。通告の無い時期（平成26年8月まで）も、会議録から起こして入れる。

## 出典の書き方

番号のない議事は、議会だよりの審議結果の表に載らない。
そのため、出典は会議録だけにして、「件名・結果は本会議録によります（市の番号が無い議事のため、議会だよりの審議結果には載っていません）」と書く。

## 種類を足すとき

1. この表に行を足す。
2. コードの一覧（`packages/shared/src/council/site-bill-number.ts` の `SITE_NUMBER_KINDS`）に足す。
3. 結果の語が新しいときは、`packages/seed/kasama/types.ts` の `KasamaResultLabel` と、`web/src/features/bills/shared/utils/bill-result-label.ts` にも足す（足さないと、サイトでは「可決」と表示される）。
